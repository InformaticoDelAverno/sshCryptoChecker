# `data/profiles/pci-dss-4/` — PCI DSS v4.0

**PCI Security Standards Council**. *Strong cryptography* tal y como PCI la define: al menos 112 bits efectivos y gestión de claves adecuada.

PCI no publica listas de algoritmos SSH: lo que se codifica aquí es su definición de glosario aplicada a lo que un servidor ofrece.
