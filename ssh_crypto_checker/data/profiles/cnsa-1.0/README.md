# `data/profiles/cnsa-1.0/` — CNSA 1.0 (transitional suite)

**NSA**. La suite clásica de la NSA, la que los sistemas de seguridad nacional usan hoy mientras migran a CNSA 2.0: AES-256, SHA-384, P-384 y RSA o DH de 3072 bits o más.

Alcanzable con el software SSH que existe, a diferencia de CNSA 2.0.
