# `data/profiles/nist-sp-800-131a/` — NIST SP 800-131A Rev. 2

**NIST**. La transición base de NIST: al menos 112 bits, sin firmas SHA-1 y sin 3DES a partir de 2023. Casi todo lo demás se apoya en ella.

Es el suelo, no el techo: pasarla no dice que la configuración sea buena, dice que no es de las que ya estaban prohibidas.
