# `docs/` — documentación de sshCryptoChecker

La documentación es **bilingüe** y está separada por idioma, con el mismo
contenido y los mismos nombres de fichero en cada uno:

- [`es/`](es/README.md) — **español**: el manual (`README.md`), el índice de las
  guías de extensión (`extender.md`) y las guías.
- [`en/`](en/README.md) — **English**: the manual (`README.md`), the extension
  guide index (`extender.md`) and the guides.

Y un subdirectorio común a los dos idiomas:

- `estandares/` — los documentos oficiales (NIST, BSI,
  BOE, ANSSI, IETF…) de los que salen los perfiles de conformidad, con la URL de
  origen y la huella de cada uno.

> El [README principal](../README.md) del repositorio redirige a cada manual.
